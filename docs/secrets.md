# Environment Variables and Secrets

Do not edit `.dev.vars`, `.env.local`, or `.env.production` by hand. They are
generated by `bin/fetch-secrets`.

## Secret projects

| ZeroVault project | Environment | Target |
|---|---|---|
| `zero-api` | development | `apps/agent-api/.dev.vars` |
| `zero-web` | development, production | `apps/agent-web/.env.local`, `.env.production` |
| `zerovault` | development, production | `apps/vault-api/.dev.vars`, dashboard Worker secrets |
| `zerovault-web` | development, production | `apps/dashboard-web/.env`, `.env.production` |

Set `ZEROVAULT_API_KEY` in your shell. `ZEROVAULT_API_URL` is optional and
defaults to `https://api.zeroapps.dev/vault`.

```bash
bin/fetch-secrets
bin/sync-secrets-to-cloudflare
```

The CLI is `pnpm dlx zerovault-cli@0.2.2`. The public dashboard is
`https://dash.zeroapps.dev/vault`; CLI traffic uses the API host, not the browser
origin.
