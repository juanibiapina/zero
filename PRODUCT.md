# Product

## Register

product

## Users

Anyone who wants a personal AI assistant accessible through Telegram. Not restricted to developers. Users arrive at this web app to set up their account: linking Telegram, granting Google Workspace access, and optionally configuring external storage. They do this once, then interact with the bot entirely through Telegram.

## Product Purpose

Zero is the bridge between a user's Telegram account and a personal AI coding agent. The web app exists solely for account setup and service connections. Success means a user finishes configuration in under a minute and never needs to return unless changing a connection.

## Brand Personality

Minimal, quiet, direct. The interface should feel like it isn't there. No decoration, no personality injection, no visual noise. White space is the primary design material. The ZeroVault project dashboard is the reference point: black text on white, simple controls, nothing extra.

## Anti-references

- Colorful SaaS dashboards with gradients, illustrations, and marketing copy baked into the product UI
- Busy settings pages with tabs, sidebars, and nested sections for what amounts to three connections
- "Friendly" onboarding flows with mascots, progress bars, or celebration animations

## Design Principles

1. **Ordinary until needed.** Controls look like what they are. No styled-up versions of standard inputs, no custom components where native ones work. The interface is unremarkable on purpose.
2. **One screen, one job.** The entire app is a single page with three connection sections. No routing, no navigation hierarchy, no feature creep.
3. **Show state, not status.** Connected or not. Working or broken. No intermediate states dressed up with spinners or skeleton screens beyond what's needed for a network round-trip.

## Accessibility & Inclusion

WCAG AA. Standard contrast ratios, keyboard navigation, screen reader support. No reduced-motion concerns given the minimal interaction surface.
