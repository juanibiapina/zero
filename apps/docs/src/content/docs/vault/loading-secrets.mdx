---
title: Loading secrets into a process
description: Load ZeroVault secrets into any process, service, or CI job with the zero CLI.
---

`zero vault secrets download` writes an environment's secrets in the format the
target reads, so any process, container, or CI job can load them. The `zero` CLI
runs anywhere Node runs. Every download is plaintext, so delete the file once it is
loaded.

## Into a .env file

Write the environment as `KEY=VALUE` lines and let your app read them:

```bash
zero vault secrets download -p demo -e production -f env -o .env
node -r dotenv/config server.js
rm .env
```

`-f env` (the default) emits one `KEY=VALUE` per line.

## Into a CI job, no file on disk

Emit shell `export` lines and source them into the current shell, so nothing
touches the disk:

```bash
eval "$(zero vault secrets download -p demo -e production -f shell)"
```

`-f shell` emits `export KEY="VALUE"` lines ready for `eval` or sourcing.

## Formats

`-f` (`--format`) picks the output; `-o` (`--output`) writes to a file instead of
stdout.

| Format | Output |
|---|---|
| `env` (default) | `KEY=VALUE` lines |
| `shell` | `export KEY="VALUE"` lines for sourcing |
| `json` | a flat `{ "KEY": "VALUE" }` object |
| `yaml` | `KEY: "VALUE"` lines |
